# 2023 电赛 E 题 · 运动目标控制与自动追踪系统

## 任务

在 2 m 距离外的靶面上，用**双轴云台 + 激光笔**完成三类任务：

1. **轨迹绘制**：激光按指定几何图形在靶面上准确走位；
2. **视觉循迹**：识别靶面上的目标/路径，驱动云台跟随；
3. **自动追踪**：识别并锁定运动中的红色/绿色目标。

## 硬件方案

| 部件 | 选型 | 说明 |
|---|---|---|
| 视觉 + 主控（基础部分） | **K230**（立创·庐山派 CanMV，MicroPython） | 摄像头采集 + 色块识别 + 舵机 PWM 输出 |
| 云台舵机 | TBS-K20 ×2 | X 轴 GPIO42 / PWM0，Y 轴 GPIO52 / PWM4；50 Hz，脉宽 0.5–2.5 ms |
| 主控（发挥部分） | **STM32F103** | 由 K230 通过串口指令驱动，控制红色激光云台做随机轨迹 |
| 激光 | 红色激光笔（基础）、绿色激光笔（发挥追踪） | — |

## 关键设计

### 1. 按键状态管理（5 键）

```
KEY1 (GPIO 27) → 复位：停止当前任务，云台回中，返回主菜单
KEY2 (GPIO 14) → 功能 1：舵机云台绘制正方形轨迹
KEY3 (GPIO 61) → 功能 2：视觉引导的矢量循迹
KEY4 (GPIO 40) → 功能 3：自动追踪红/绿目标并锁定
KEY5 (GPIO 46) → 暂停 / 继续当前任务
```

`check_global_controls(gimbal_instance, display_instance)` 在每个控制循环里被调用，保证**任意时刻都能响应复位与暂停**——这是把 5 个按键做成全局状态机、而不是散落在各功能里的结果。

### 2. 舵机 PWM 脉宽映射（`云台驱动.py`）

```python
SERVO_FREQ_HZ   = 50        # 舵机 PWM 频率
PULSE_MIN_MS    = 0.5       # 最小脉宽
PULSE_MAX_MS    = 2.5       # 最大脉宽
PULSE_CENTER_MS = 1.6       # 居中脉宽
SQUARE_OFFSET_MS = 0.1      # 正方形边长的一半（脉宽偏移量）

INITIAL_POS  = (1.6, 1.6)
TOP_LEFT     = (1.6-0.1, 1.6+0.1)
TOP_RIGHT    = (1.6+0.1, 1.6+0.1)
BOTTOM_RIGHT = (1.6+0.1, 1.6-0.1)
BOTTOM_LEFT  = (1.6-0.1, 1.6-0.1)
```

> **注意方向约定**：Y 轴脉宽增大通常使云台**向上**移动，X 轴脉宽减小通常使云台**向左**移动——两个轴的方向约定相反，这是实测标定的结果，写在了代码注释里。

`move_servos(pwm_x, pwm_y, target_pos)` 同时更新两个轴的占空比，保证两条对角线的运动是"同时到达"而不是"先横后纵"。

### 3. 视觉识别（`摄像头追踪测试代码.py`）

在 **LAB 色彩空间**做阈值分割（相比 RGB，LAB 对光照变化更鲁棒），再用 Blob 检测求色块中心：

```python
DISPLAY_MODE = "LCD"        # VIRT / LCD / HDMI
SENSOR_ID    = 2

# 红色目标 rgb(254,150,200) → LAB 中心约 L=75, a=40, b=-5
RED_THRESHOLD   = [(30, 95, 20, 70, -25, 25)]
# 绿色目标 rgb(138,242,133) → LAB 中心约 L=85, a=-45, b=40
GREEN_THRESHOLD = [(40, 98, -80, -30, 20, 80)]

BLOB_AREA_THRESHOLD = 2     # 过滤过小噪点
```

**阈值设计思路**：L（亮度）通道范围放得很宽以适应不同光照；a（红/绿）通道集中在目标色域；b（黄/蓝）通道允许一定色差。这是"牺牲一点精确度换取光照鲁棒性"的取舍。

## 单板集成方案（工程取舍）

题目要求基础部分与发挥部分各用一块 K230。**我只有一块开发板**，因此：

- 基础部分：K230 直接驱动红色激光笔绘制轨迹；
- 发挥部分：K230 通过串口指令驱动 **STM32** 控制红色激光云台做随机轨迹移动，同时 K230 自身控制绿色激光追踪。

若严格按题目要求复现，需要两块 K230。
