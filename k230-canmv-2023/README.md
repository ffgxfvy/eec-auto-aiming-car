# K230 CanMV 代码说明（2023 电赛 E 题）

本目录是 **2023 年全国大学生电子设计竞赛 E 题「运动目标控制与自动追踪系统」** 的 K230 端实现，运行平台为立创·庐山派 **K230-CanMV**（MicroPython）。

## 文件

| 文件 | 大小 | 说明 |
|---|---|---|
| `main.py` | 37.6 KB | **主程序**。三种功能的完整实现 + 5 按键全局状态管理 |
| `云台驱动.py` | 5.5 KB | 双轴舵机 PWM 驱动、轨迹点定义（可独立运行） |
| `摄像头追踪测试代码.py` | 7.9 KB | 视觉识别原型：LAB 阈值分割 + Blob 检测 + LCD 显示 |
| `基础34题.py` | 15.2 KB | 基础上机题分模块验证 |
| `发挥部分.py` | 14.0 KB | 发挥部分功能验证 |
| `readme.txt` | — | 原始设计说明（含单板集成方案） |

除 `main.py` 外，其余脚本都是开发测试过程中产生的，**均可独立运行**。

## 运行

1. 安装 CanMV IDE（立创·庐山派 K230 官方工具链）；
2. 连接开发板，将 `.py` 文件通过 IDE 下载到板卡（或拷入 SD 卡）；
3. 按键操作：

| 按键 | GPIO | 功能 |
|---|---|---|
| KEY1 | 27 | 复位：停止任务、云台回中、返回主菜单 |
| KEY2 | 14 | 功能 1：舵机云台绘制正方形轨迹 |
| KEY3 | 61 | 功能 2：视觉引导的矢量循迹 |
| KEY4 | 40 | 功能 3：自动追踪红/绿目标并锁定 |
| KEY5 | 46 | 暂停 / 继续 |

## 硬件接线

| 外设 | 引脚 | 备注 |
|---|---|---|
| X 轴舵机 | GPIO 42（PWM ID 0） | TBS-K20，50 Hz，0.5–2.5 ms |
| Y 轴舵机 | GPIO 52（PWM ID 4） | 同上 |
| 摄像头 | Sensor ID 2 | 显示模式可选 VIRT / LCD / HDMI |
