# K230 CanMV 第三方参考代码说明（2023 电赛 E 题开源归档）

> **来源说明**：本目录内容系备赛阶段收集的**第三方公开开源练习代码（非本人原创）**。原始 `readme.txt` 中作者注明代码注释借助 Gemini 2.5 Flash 生成，并用单块 K230 + STM32 完成 2023 E 题功能测试；现归档于 `references/` 仅供对照阅读。

## 目录文件清单

| 文件 | 说明 |
|---|---|
| `main.py` | 第三方作者整合的主程序：三大功能状态机 + 5 按键切换 |
| `云台驱动.py` | 50 Hz 双轴舵机 PWM 驱动与轨迹插值示例 |
| `摄像头追踪测试代码.py` | LAB 阈值分割 + Blob 色块追踪测试脚本 |
| `基础34题.py` / `发挥部分.py` | 分阶段验证脚本 |
| `readme.txt` | 原始发布者保留的设计与分工自述 |

## 原作者引脚定义（供阅读参考）

| 外设 | GPIO / 外设 | 原始备注 |
|---|---|---|
| X 轴舵机 | GPIO 42（PWM ID 0） | 50 Hz，`0.5–2.5 ms` |
| Y 轴舵机 | GPIO 52（PWM ID 4） | 同上 |
| 摄像头 | Sensor ID 2 | 支持 VIRT / LCD / HDMI 显示 |
| 按键 KEY1–5 | GPIO 27 / 14 / 61 / 40 / 46 | 复位、画框、循迹、追踪、暂停 |
